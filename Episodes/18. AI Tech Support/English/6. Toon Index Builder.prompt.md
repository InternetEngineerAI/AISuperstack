  "[filename] not found in index. No changes made.

- Update last_updated date in header
- All other entries remain unchanged

═══════════════════════════════════════════════════════

FILENAME CONSTRUCTION RULE:
Use the actual uploaded filename if visible.
If pasted as text — construct using this pattern:
  [Manufacturer]_[Product_Name]_[Model_Number].toon
  Spaces replaced with underscores.
  Example: DJI_Osmo_Action_OAS100.toon
  Example: Sony_Alpha_7R_ILCE-7R.toon

SEARCH TERMS RULE:
Generate search_terms from manufacturer, product_name,
model_number, and product_category combined. Include
obvious common alternate names or abbreviations.
Examples:
  DJI Osmo Action OAS100 action camera
  Sony Alpha 7R ILCE-7R mirrorless camera a7r

DO NOT read any other section of the .toon file.
DO NOT extract troubleshooting, known issues,
specifications, video refs, or any other content.
Only TOON_HEADER and OFFICIAL_INFO are needed.
