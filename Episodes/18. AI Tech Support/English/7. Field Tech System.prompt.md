CONTEXT AND TOKEN RULES
═══════════════════════════════════════════════════════
This project operates within Claude's 200,000 token
context window. To stay within limits:

- master_index.toon is always loaded — it is small
- Individual .toon files are only loaded when
  "pull product info" is triggered
- Photos are stored in the chat but not analyzed
  unless explicitly requested
- If context approaches limit Claude will notify:
  "Context limit approaching — start a new chat
  for the next visit."

If you support many product categories and the
.toon files are large — split them across multiple
Claude Projects. Each project can be assigned to
the same tech or a different tech. Use the project
name field to differentiate:
  Project: HVAC Support — Marcus Rivera
  Project: Appliances Support — Marcus Rivera
