### Protocole de Reconnaissance Rapide

Lors du travail avec des formulaires PDF créés par Sejda ou des éditeurs PDF en ligne similaires, utilisez cette approche rationalisée :

**Étape 1 : Extraction Rapide des Champs**
Si le script standard `extract_form_field_info.py` renvoie 0 champs mais que `check_fillable_fields.py` confirme l'existence de champs remplissables, utilisez cette méthode d'extraction directe :
```python
from pypdf import PdfReader

reader = PdfReader("chemin/vers/formulaire.pdf")
if "/AcroForm" in reader.trailer["/Root"]:
    fields = reader.trailer["/Root"]["/AcroForm"]["/Fields"]
    field_names = []
    for field in fields:
        field_obj = field.get_object()
        if "/T" in field_obj:
            field_names.append(field_obj["/T"])
    print("Noms des champs:", field_names)
```

**Étape 2 : Remplir en Utilisant la Méthode Clone de pypdf**
Les formulaires créés avec Sejda nécessitent l'utilisation de `clone_reader_document_root()` au lieu de `append_pages_from_reader()` :
```python
from pypdf import PdfReader, PdfWriter

reader = PdfReader("input.pdf")
writer = PdfWriter()

# Critique : Utiliser clone_reader_document_root pour les formulaires Sejda
writer.clone_reader_document_root(reader)

# Définir les valeurs des champs
field_values = {
    "NomChamp1": "Valeur1",
    "NomChamp2": "Valeur2",
    # ... etc
}

# Mettre à jour les champs
writer.update_page_form_field_values(writer.pages[0], field_values)

# Sauvegarder
with open("output.pdf", "wb") as f:
    writer.write(f)
```

### Modèles de Nommage Courants des Champs Sejda

Sejda utilise typiquement ces conventions de nommage :
- **Informations Client :** `Date`, `Estimate No`, `Name`, `Address`, `CustomerPhone`, `CustomerEmail`
- **Lignes d'Articles :** `Description1-N`, `Qty1-N`, `Cost1-N`, `TotalCost1-N` (où N est le numéro de ligne)
- **Totaux :** `SubTotal`, `Taxes`, `GrandTotal`
- **Notes :** `Notes` (souvent multiligne avec drapeau 4096)

### Drapeaux de Reconnaissance
- Les champs Sejda incluent une entrée `/Sejda` dans les objets de champ
- Le type de champ `/FT: /Tx` indique un champ texte
- Le drapeau `/Ff: 4096` indique un champ texte multiligne
- Tous les champs Sejda ont typiquement un tableau `/Kids` avec 1 enfant

### Arbre de Décision Voie Rapide
1. Vérifier si remplissable : `check_fillable_fields.py`
2. Si remplissable mais extraction renvoie 0 : Utiliser l'extraction directe pypdf
3. Inspecter la structure des champs : Rechercher `/T` (nom) et `/FT` (type)
4. Remplir en utilisant la méthode clone_reader_document_root
5. Pas besoin de méthode de repli par annotation

Cette approche réduit le temps de reconnaissance de ~5 minutes à ~30 secondes.
