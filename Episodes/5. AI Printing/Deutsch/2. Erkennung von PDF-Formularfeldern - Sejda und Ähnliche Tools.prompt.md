## Erkennung von PDF-Formularfeldern - Sejda und Ähnliche Tools

### Schnelles Erkennungsprotokoll

Beim Arbeiten mit PDF-Formularen, die von Sejda oder ähnlichen Online-PDF-Editoren erstellt wurden, verwenden Sie diesen optimierten Ansatz:

**Schritt 1: Schnelle Feldextraktion**
Wenn das Standard-Skript `extract_form_field_info.py` 0 Felder zurückgibt, aber `check_fillable_fields.py` bestätigt, dass ausfüllbare Felder vorhanden sind, verwenden Sie diese direkte Extraktionsmethode:
```python
from pypdf import PdfReader

reader = PdfReader("pfad/zum/formular.pdf")
if "/AcroForm" in reader.trailer["/Root"]:
    fields = reader.trailer["/Root"]["/AcroForm"]["/Fields"]
    field_names = []
    for field in fields:
        field_obj = field.get_object()
        if "/T" in field_obj:
            field_names.append(field_obj["/T"])
    print("Feldnamen:", field_names)
```

**Schritt 2: Ausfüllen mit pypdf-Clone-Methode**
Mit Sejda erstellte Formulare erfordern die Verwendung von `clone_reader_document_root()` anstelle von `append_pages_from_reader()`:
```python
from pypdf import PdfReader, PdfWriter

reader = PdfReader("input.pdf")
writer = PdfWriter()

# Kritisch: clone_reader_document_root für Sejda-Formulare verwenden
writer.clone_reader_document_root(reader)

# Feldwerte definieren
field_values = {
    "Feldname1": "Wert1",
    "Feldname2": "Wert2",
    # ... usw.
}

# Felder aktualisieren
writer.update_page_form_field_values(writer.pages[0], field_values)

# Speichern
with open("output.pdf", "wb") as f:
    writer.write(f)
```

### Häufige Sejda-Feldnamenmuster

Sejda verwendet typischerweise diese Namenskonventionen:
- **Kundeninfo:** `Date`, `Estimate No`, `Name`, `Address`, `CustomerPhone`, `CustomerEmail`
- **Positionsartikel:** `Description1-N`, `Qty1-N`, `Cost1-N`, `TotalCost1-N` (wobei N die Zeilennummer ist)
- **Summen:** `SubTotal`, `Taxes`, `GrandTotal`
- **Notizen:** `Notes` (oft mehrzeilig mit Flag 4096)

### Erkennungsflags
- Sejda-Felder enthalten `/Sejda`-Eintrag in Feldobjekten
- Feldtyp `/FT: /Tx` zeigt Textfeld an
- Flag `/Ff: 4096` zeigt mehrzeiliges Textfeld an
- Alle Sejda-Felder haben typischerweise `/Kids`-Array mit 1 Kind

### Schnellspur-Entscheidungsbaum
1. Ausfüllbarkeit prüfen: `check_fillable_fields.py`
2. Wenn ausfüllbar, aber Extraktion 0 zurückgibt: Direkte pypdf-Extraktion verwenden
3. Feldstruktur inspizieren: Nach `/T` (Name) und `/FT` (Typ) suchen
4. Mit clone_reader_document_root-Methode ausfüllen
5. Keine Notwendigkeit für Annotations-Fallback-Methode

Dieser Ansatz reduziert die Erkennungszeit von ~5 Minuten auf ~30 Sekunden.
