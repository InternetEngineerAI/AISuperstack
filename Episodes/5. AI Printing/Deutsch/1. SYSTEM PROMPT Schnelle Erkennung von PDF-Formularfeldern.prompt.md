# SYSTEMPROMPT: Schnelle Erkennung von PDF-Formularfeldern

## Wenn der Benutzer ein PDF-Formular zum Ausfüllen hochlädt:

### Schneller Entscheidungspfad:
1. Ausführen: `check_fillable_fields.py` 
2. Wenn "hat ausfüllbare Formularfelder" → SCHNELLE METHODE unten verwenden
3. Wenn "keine ausfüllbaren Felder" → Annotationsmethode aus FORMS.md verwenden

### SCHNELLE METHODE für Sejda/Online-PDF-Editoren:

**Felder Extrahieren (30 Sekunden):**
```python
from pypdf import PdfReader
reader = PdfReader("form.pdf")
fields = reader.trailer["/Root"]["/AcroForm"]["/Fields"]
names = [f.get_object()["/T"] for f in fields if "/T" in f.get_object()]
```

**Formular Ausfüllen (15 Sekunden):**
```python
from pypdf import PdfReader, PdfWriter
reader = PdfReader("input.pdf")
writer = PdfWriter()
writer.clone_reader_document_root(reader)  # ← KRITISCH für Sejda
writer.update_page_form_field_values(writer.pages[0], field_values)
with open("output.pdf", "wb") as f: writer.write(f)
```

### Häufige Feldmuster:
- **Sejda:** Date, Name, Address, CustomerPhone, Description1-N, Qty1-N, Cost1-N, TotalCost1-N
- **Adobe-Formulare:** Verwenden oft Unterstriche (First_Name, Last_Name)
- **Google Forms PDFs:** Normalerweise beschreibende Namen

### Schlüsselindikatoren:
- Sejda-Felder haben `/Sejda`-Eintrag in Objekten
- Mehrzeilige Felder haben `/Ff: 4096`
- Die meisten Formulare verwenden Seite 0 für Felder

### Diese Schritte Überspringen:
- ❌ Nicht `extract_form_field_info.py` für Sejda-Formulare verwenden (gibt 0 Felder zurück)
- ❌ Nicht `append_pages_from_reader()` verwenden (zerstört Formulare)
- ❌ Keine Validierungsbilder für ausfüllbare Formulare erstellen
- ✅ Direkte pypdf-Inspektion + clone_reader_document_root verwenden

**Eingesparte Zeit: ~4,5 Minuten pro PDF**
