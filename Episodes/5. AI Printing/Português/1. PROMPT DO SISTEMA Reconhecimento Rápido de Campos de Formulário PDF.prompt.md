## Quando o usuário carregar um formulário PDF para preencher:

### Caminho de Decisão Rápido:
1. Executar: `check_fillable_fields.py` 
2. Se "possui campos de formulário preenchíveis" → Use o MÉTODO RÁPIDO abaixo
3. Se "sem campos preenchíveis" → Use o método de anotação do FORMS.md

### MÉTODO RÁPIDO para Sejda/Editores de PDF Online:

**Extrair Campos (30 segundos):**
```python
from pypdf import PdfReader
reader = PdfReader("form.pdf")
fields = reader.trailer["/Root"]["/AcroForm"]["/Fields"]
names = [f.get_object()["/T"] for f in fields if "/T" in f.get_object()]
```

**Preencher Formulário (15 segundos):**
```python
from pypdf import PdfReader, PdfWriter
reader = PdfReader("input.pdf")
writer = PdfWriter()
writer.clone_reader_document_root(reader)  # ← CRÍTICO para Sejda
writer.update_page_form_field_values(writer.pages[0], field_values)
with open("output.pdf", "wb") as f: writer.write(f)
```

### Padrões Comuns de Campos:
- **Sejda:** Date, Name, Address, CustomerPhone, Description1-N, Qty1-N, Cost1-N, TotalCost1-N
- **Formulários Adobe:** Frequentemente usam sublinhados (First_Name, Last_Name)
- **PDFs Google Forms:** Geralmente nomes descritivos

### Indicadores Chave:
- Campos Sejda têm entrada `/Sejda` nos objetos
- Campos multilinha têm `/Ff: 4096`
- A maioria dos formulários usa página 0 para campos

### Pular Estas Etapas:
- ❌ Não use `extract_form_field_info.py` para formulários Sejda (retorna 0 campos)
- ❌ Não use `append_pages_from_reader()` (quebra formulários)
- ❌ Não crie imagens de validação para formulários preenchíveis
- ✅ USE inspeção direta pypdf + clone_reader_document_root

**Tempo economizado: ~4,5 minutos por PDF**
