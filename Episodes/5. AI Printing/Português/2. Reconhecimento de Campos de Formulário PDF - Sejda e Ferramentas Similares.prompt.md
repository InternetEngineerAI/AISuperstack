## Reconhecimento de Campos de Formulário PDF - Sejda e Ferramentas Similares

### Protocolo de Reconhecimento Rápido

Ao trabalhar com formulários PDF criados pelo Sejda ou editores de PDF online similares, use esta abordagem simplificada:

**Passo 1: Extração Rápida de Campos**
Se o script padrão `extract_form_field_info.py` retornar 0 campos mas `check_fillable_fields.py` confirmar que campos preenchíveis existem, use este método de extração direta:
```python
from pypdf import PdfReader

reader = PdfReader("caminho/para/formulario.pdf")
if "/AcroForm" in reader.trailer["/Root"]:
    fields = reader.trailer["/Root"]["/AcroForm"]["/Fields"]
    field_names = []
    for field in fields:
        field_obj = field.get_object()
        if "/T" in field_obj:
            field_names.append(field_obj["/T"])
    print("Nomes dos campos:", field_names)
```

**Passo 2: Preencher Usando o Método Clone do pypdf**
Formulários criados com Sejda requerem o uso de `clone_reader_document_root()` ao invés de `append_pages_from_reader()`:
```python
from pypdf import PdfReader, PdfWriter

reader = PdfReader("input.pdf")
writer = PdfWriter()

# Crítico: Use clone_reader_document_root para formulários Sejda
writer.clone_reader_document_root(reader)

# Definir valores dos campos
field_values = {
    "NomeCampo1": "Valor1",
    "NomeCampo2": "Valor2",
    # ... etc
}

# Atualizar campos
writer.update_page_form_field_values(writer.pages[0], field_values)

# Salvar
with open("output.pdf", "wb") as f:
    writer.write(f)
```

### Padrões Comuns de Nomenclatura de Campos Sejda

Sejda tipicamente usa estas convenções de nomenclatura:
- **Informações do Cliente:** `Date`, `Estimate No`, `Name`, `Address`, `CustomerPhone`, `CustomerEmail`
- **Itens de Linha:** `Description1-N`, `Qty1-N`, `Cost1-N`, `TotalCost1-N` (onde N é o número da linha)
- **Totais:** `SubTotal`, `Taxes`, `GrandTotal`
- **Notas:** `Notes` (frequentemente multilinha com flag 4096)

### Sinalizadores de Reconhecimento
- Campos Sejda incluem entrada `/Sejda` nos objetos de campo
- Tipo de campo `/FT: /Tx` indica campo de texto
- Sinalizador `/Ff: 4096` indica campo de texto multilinha
- Todos os campos Sejda tipicamente têm array `/Kids` com 1 filho

### Árvore de Decisão Via Rápida
1. Verificar preenchível: `check_fillable_fields.py`
2. Se preenchível mas extração retorna 0: Usar extração direta pypdf
3. Inspecionar estrutura de campos: Procurar `/T` (nome) e `/FT` (tipo)
4. Preencher usando método clone_reader_document_root
5. Não há necessidade de método alternativo de anotação

Esta abordagem reduz o tempo de reconhecimento de ~5 minutos para ~30 segundos.
