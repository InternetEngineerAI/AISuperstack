## Apabila pengguna memuat naik borang PDF untuk diisi:

### Laluan Keputusan Pantas:
1. Jalankan: `check_fillable_fields.py` 
2. Jika "mempunyai medan borang boleh diisi" → Guna KAEDAH PANTAS di bawah
3. Jika "tiada medan boleh diisi" → Guna kaedah anotasi daripada FORMS.md

### KAEDAH PANTAS untuk Sejda/Editor PDF Dalam Talian:

**Ekstrak Medan (30 saat):**
```python
from pypdf import PdfReader
reader = PdfReader("form.pdf")
fields = reader.trailer["/Root"]["/AcroForm"]["/Fields"]
names = [f.get_object()["/T"] for f in fields if "/T" in f.get_object()]
```

**Isi Borang (15 saat):**
```python
from pypdf import PdfReader, PdfWriter
reader = PdfReader("input.pdf")
writer = PdfWriter()
writer.clone_reader_document_root(reader)  # ← KRITIKAL untuk Sejda
writer.update_page_form_field_values(writer.pages[0], field_values)
with open("output.pdf", "wb") as f: writer.write(f)
```

### Corak Medan Biasa:
- **Sejda:** Date, Name, Address, CustomerPhone, Description1-N, Qty1-N, Cost1-N, TotalCost1-N
- **Borang Adobe:** Selalunya guna garis bawah (First_Name, Last_Name)
- **PDF Google Forms:** Biasanya nama deskriptif

### Penunjuk Utama:
- Medan Sejda mempunyai entri `/Sejda` dalam objek
- Medan berbilang baris mempunyai `/Ff: 4096`
- Kebanyakan borang guna halaman 0 untuk medan

### Langkau Langkah-Langkah Ini:
- ❌ Jangan guna `extract_form_field_info.py` untuk borang Sejda (mengembalikan 0 medan)
- ❌ Jangan guna `append_pages_from_reader()` (merosakkan borang)
- ❌ Jangan cipta imej pengesahan untuk borang boleh diisi
- ✅ GUNA pemeriksaan langsung pypdf + clone_reader_document_root

**Masa yang dijimatkan: ~4.5 minit setiap PDF**
