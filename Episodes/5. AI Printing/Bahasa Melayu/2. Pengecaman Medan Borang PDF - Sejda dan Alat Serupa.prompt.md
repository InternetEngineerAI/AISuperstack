### Protokol Pengecaman Pantas

Semasa bekerja dengan borang PDF yang dicipta oleh Sejda atau editor PDF dalam talian yang serupa, gunakan pendekatan yang diperkemas ini:

**Langkah 1: Ekstraksi Medan Pantas**
Jika skrip standard `extract_form_field_info.py` mengembalikan 0 medan tetapi `check_fillable_fields.py` mengesahkan medan boleh diisi wujud, gunakan kaedah ekstraksi langsung ini:
```python
from pypdf import PdfReader

reader = PdfReader("laluan/ke/borang.pdf")
if "/AcroForm" in reader.trailer["/Root"]:
    fields = reader.trailer["/Root"]["/AcroForm"]["/Fields"]
    field_names = []
    for field in fields:
        field_obj = field.get_object()
        if "/T" in field_obj:
            field_names.append(field_obj["/T"])
    print("Nama medan:", field_names)
```

**Langkah 2: Isi Menggunakan Kaedah Clone pypdf**
Borang yang dicipta dengan Sejda memerlukan penggunaan `clone_reader_document_root()` dan bukannya `append_pages_from_reader()`:
```python
from pypdf import PdfReader, PdfWriter

reader = PdfReader("input.pdf")
writer = PdfWriter()

# Kritikal: Guna clone_reader_document_root untuk borang Sejda
writer.clone_reader_document_root(reader)

# Tentukan nilai medan
field_values = {
    "NamaMedan1": "Nilai1",
    "NamaMedan2": "Nilai2",
    # ... dll
}

# Kemas kini medan
writer.update_page_form_field_values(writer.pages[0], field_values)

# Simpan
with open("output.pdf", "wb") as f:
    writer.write(f)
```

### Corak Penamaan Medan Sejda Biasa

Sejda biasanya menggunakan konvensyen penamaan ini:
- **Maklumat Pelanggan:** `Date`, `Estimate No`, `Name`, `Address`, `CustomerPhone`, `CustomerEmail`
- **Item Baris:** `Description1-N`, `Qty1-N`, `Cost1-N`, `TotalCost1-N` (di mana N ialah nombor baris)
- **Jumlah:** `SubTotal`, `Taxes`, `GrandTotal`
- **Nota:** `Notes` (selalunya berbilang baris dengan bendera 4096)

### Bendera Pengecaman
- Medan Sejda termasuk entri `/Sejda` dalam objek medan
- Jenis medan `/FT: /Tx` menunjukkan medan teks
- Bendera `/Ff: 4096` menunjukkan medan teks berbilang baris
- Semua medan Sejda biasanya mempunyai array `/Kids` dengan 1 anak

### Pokok Keputusan Laluan Pantas
1. Semak boleh diisi: `check_fillable_fields.py`
2. Jika boleh diisi tetapi ekstrak mengembalikan 0: Guna ekstraksi langsung pypdf
3. Periksa struktur medan: Cari `/T` (nama) dan `/FT` (jenis)
4. Isi menggunakan kaedah clone_reader_document_root
5. Tidak perlu kaedah sandaran anotasi

Pendekatan ini mengurangkan masa pengecaman daripada ~5 minit kepada ~30 saat.
