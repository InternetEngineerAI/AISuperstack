## Riconoscimento Campi Modulo PDF - Sejda e Strumenti Simili

### Protocollo di Riconoscimento Rapido

Quando si lavora con moduli PDF creati da Sejda o editor PDF online simili, usa questo approccio semplificato:

**Passo 1: Estrazione Rapida dei Campi**
Se lo script standard `extract_form_field_info.py` restituisce 0 campi ma `check_fillable_fields.py` conferma l'esistenza di campi compilabili, usa questo metodo di estrazione diretta:
```python
from pypdf import PdfReader

reader = PdfReader("percorso/al/modulo.pdf")
if "/AcroForm" in reader.trailer["/Root"]:
    fields = reader.trailer["/Root"]["/AcroForm"]["/Fields"]
    field_names = []
    for field in fields:
        field_obj = field.get_object()
        if "/T" in field_obj:
            field_names.append(field_obj["/T"])
    print("Nomi dei campi:", field_names)
```

**Passo 2: Compilare Usando il Metodo Clone di pypdf**
I moduli creati con Sejda richiedono l'uso di `clone_reader_document_root()` invece di `append_pages_from_reader()`:
```python
from pypdf import PdfReader, PdfWriter

reader = PdfReader("input.pdf")
writer = PdfWriter()

# Critico: Usare clone_reader_document_root per moduli Sejda
writer.clone_reader_document_root(reader)

# Definire valori dei campi
field_values = {
    "NomeCampo1": "Valore1",
    "NomeCampo2": "Valore2",
    # ... ecc
}

# Aggiornare campi
writer.update_page_form_field_values(writer.pages[0], field_values)

# Salvare
with open("output.pdf", "wb") as f:
    writer.write(f)
```

### Modelli Comuni di Denominazione Campi Sejda

Sejda usa tipicamente queste convenzioni di denominazione:
- **Informazioni Cliente:** `Date`, `Estimate No`, `Name`, `Address`, `CustomerPhone`, `CustomerEmail`
- **Voci di Riga:** `Description1-N`, `Qty1-N`, `Cost1-N`, `TotalCost1-N` (dove N è il numero di riga)
- **Totali:** `SubTotal`, `Taxes`, `GrandTotal`
- **Note:** `Notes` (spesso multilinea con flag 4096)

### Flag di Riconoscimento
- I campi Sejda includono voce `/Sejda` negli oggetti campo
- Il tipo di campo `/FT: /Tx` indica campo di testo
- Il flag `/Ff: 4096` indica campo di testo multilinea
- Tutti i campi Sejda hanno tipicamente array `/Kids` con 1 figlio

### Albero Decisionale Percorso Veloce
1. Verificare compilabilità: `check_fillable_fields.py`
2. Se compilabile ma estrazione restituisce 0: Usare estrazione diretta pypdf
3. Ispezionare struttura campi: Cercare `/T` (nome) e `/FT` (tipo)
4. Compilare usando metodo clone_reader_document_root
5. Non serve metodo alternativo di annotazione

Questo approccio riduce il tempo di riconoscimento da ~5 minuti a ~30 secondi.
