## Reconocimiento de Campos de Formulario PDF - Sejda y Herramientas Similares

### Protocolo de Reconocimiento Rápido

Cuando trabajes con formularios PDF creados por Sejda o editores PDF en línea similares, usa este enfoque simplificado:

**Paso 1: Extracción Rápida de Campos**
Si el script estándar `extract_form_field_info.py` devuelve 0 campos pero `check_fillable_fields.py` confirma que existen campos rellenables, usa este método de extracción directa:
```python
from pypdf import PdfReader

reader = PdfReader("ruta/al/formulario.pdf")
if "/AcroForm" in reader.trailer["/Root"]:
    fields = reader.trailer["/Root"]["/AcroForm"]["/Fields"]
    field_names = []
    for field in fields:
        field_obj = field.get_object()
        if "/T" in field_obj:
            field_names.append(field_obj["/T"])
    print("Nombres de campos:", field_names)
```

**Paso 2: Rellenar Usando el Método Clone de pypdf**
Los formularios creados con Sejda requieren usar `clone_reader_document_root()` en lugar de `append_pages_from_reader()`:
```python
from pypdf import PdfReader, PdfWriter

reader = PdfReader("input.pdf")
writer = PdfWriter()

# Crítico: Usar clone_reader_document_root para formularios Sejda
writer.clone_reader_document_root(reader)

# Definir valores de campos
field_values = {
    "NombreCampo1": "Valor1",
    "NombreCampo2": "Valor2",
    # ... etc
}

# Actualizar campos
writer.update_page_form_field_values(writer.pages[0], field_values)

# Guardar
with open("output.pdf", "wb") as f:
    writer.write(f)
```

### Patrones Comunes de Nomenclatura de Campos en Sejda

Sejda típicamente usa estas convenciones de nomenclatura:
- **Información del Cliente:** `Date`, `Estimate No`, `Name`, `Address`, `CustomerPhone`, `CustomerEmail`
- **Líneas de Artículos:** `Description1-N`, `Qty1-N`, `Cost1-N`, `TotalCost1-N` (donde N es el número de fila)
- **Totales:** `SubTotal`, `Taxes`, `GrandTotal`
- **Notas:** `Notes` (frecuentemente multilínea con bandera 4096)

### Banderas de Reconocimiento
- Los campos Sejda incluyen entrada `/Sejda` en los objetos de campo
- El tipo de campo `/FT: /Tx` indica campo de texto
- La bandera `/Ff: 4096` indica campo de texto multilínea
- Todos los campos Sejda típicamente tienen array `/Kids` con 1 hijo

### Árbol de Decisión de Vía Rápida
1. Verificar si es rellenable: `check_fillable_fields.py`
2. Si es rellenable pero extract devuelve 0: Usar extracción directa con pypdf
3. Inspeccionar estructura de campos: Buscar `/T` (nombre) y `/FT` (tipo)
4. Rellenar usando método clone_reader_document_root
5. No es necesario el método de respaldo por anotación

Este enfoque reduce el tiempo de reconocimiento de ~5 minutos a ~30 segundos.
