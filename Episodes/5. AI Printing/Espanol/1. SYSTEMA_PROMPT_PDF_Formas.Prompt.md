# PROMPT DEL SISTEMA: Reconocimiento Rápido de Campos de Formulario PDF

## Cuando el usuario sube un formulario PDF para rellenar:

### Ruta de Decisión Rápida:
1. Ejecutar: `check_fillable_fields.py` 
2. Si "tiene campos de formulario rellenables" → Usar MÉTODO RÁPIDO a continuación
3. Si "sin campos rellenables" → Usar método de anotación de FORMS.md

### MÉTODO RÁPIDO para Sejda/Editores PDF en Línea:

**Extraer Campos (30 segundos):**
```python
from pypdf import PdfReader
reader = PdfReader("form.pdf")
fields = reader.trailer["/Root"]["/AcroForm"]["/Fields"]
names = [f.get_object()["/T"] for f in fields if "/T" in f.get_object()]
```

**Rellenar Formulario (15 segundos):**
```python
from pypdf import PdfReader, PdfWriter
reader = PdfReader("input.pdf")
writer = PdfWriter()
writer.clone_reader_document_root(reader)  # ← CRÍTICO para Sejda
writer.update_page_form_field_values(writer.pages[0], field_values)
with open("output.pdf", "wb") as f: writer.write(f)
```

### Patrones Comunes de Campos:
- **Sejda:** Date, Name, Address, CustomerPhone, Description1-N, Qty1-N, Cost1-N, TotalCost1-N
- **Formularios Adobe:** Frecuentemente usan guiones bajos (First_Name, Last_Name)
- **PDFs de Google Forms:** Generalmente nombres descriptivos

### Indicadores Clave:
- Los campos Sejda tienen entrada `/Sejda` en los objetos
- Los campos multilínea tienen `/Ff: 4096`
- La mayoría de formularios usan página 0 para campos

### Omitir Estos Pasos:
- ❌ No usar `extract_form_field_info.py` para formularios Sejda (devuelve 0 campos)
- ❌ No usar `append_pages_from_reader()` (rompe los formularios)
- ❌ No crear imágenes de validación para formularios rellenables
- ✅ SÍ usar inspección directa con pypdf + clone_reader_document_root

**Tiempo ahorrado: ~4.5 minutos por PDF**
