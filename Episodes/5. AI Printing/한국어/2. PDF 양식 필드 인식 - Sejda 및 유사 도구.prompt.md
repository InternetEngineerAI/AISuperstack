## PDF 양식 필드 인식 - Sejda 및 유사 도구

### 빠른 인식 프로토콜

Sejda 또는 유사한 온라인 PDF 편집기로 생성된 PDF 양식 작업 시 이 간소화된 접근 방식을 사용하세요:

**단계 1: 빠른 필드 추출**
표준 `extract_form_field_info.py` 스크립트가 0개 필드를 반환하지만 `check_fillable_fields.py`가 작성 가능한 필드가 존재함을 확인하는 경우, 이 직접 추출 방법을 사용하세요:
```python
from pypdf import PdfReader

reader = PdfReader("경로/양식.pdf")
if "/AcroForm" in reader.trailer["/Root"]:
    fields = reader.trailer["/Root"]["/AcroForm"]["/Fields"]
    field_names = []
    for field in fields:
        field_obj = field.get_object()
        if "/T" in field_obj:
            field_names.append(field_obj["/T"])
    print("필드 이름:", field_names)
```

**단계 2: pypdf Clone 메서드를 사용한 작성**
Sejda로 생성된 양식은 `append_pages_from_reader()` 대신 `clone_reader_document_root()`를 사용해야 합니다:
```python
from pypdf import PdfReader, PdfWriter

reader = PdfReader("input.pdf")
writer = PdfWriter()

# 중요: Sejda 양식에는 clone_reader_document_root 사용
writer.clone_reader_document_root(reader)

# 필드 값 정의
field_values = {
    "필드이름1": "값1",
    "필드이름2": "값2",
    # ... 등
}

# 필드 업데이트
writer.update_page_form_field_values(writer.pages[0], field_values)

# 저장
with open("output.pdf", "wb") as f:
    writer.write(f)
```

### 일반적인 Sejda 필드 명명 패턴

Sejda는 일반적으로 다음 명명 규칙을 사용합니다:
- **고객 정보:** `Date`, `Estimate No`, `Name`, `Address`, `CustomerPhone`, `CustomerEmail`
- **항목 라인:** `Description1-N`, `Qty1-N`, `Cost1-N`, `TotalCost1-N` (여기서 N은 행 번호)
- **합계:** `SubTotal`, `Taxes`, `GrandTotal`
- **메모:** `Notes` (플래그 4096으로 여러 줄인 경우가 많음)

### 인식 플래그
- Sejda 필드는 필드 객체에 `/Sejda` 항목 포함
- 필드 유형 `/FT: /Tx`는 텍스트 필드를 나타냄
- 플래그 `/Ff: 4096`은 여러 줄 텍스트 필드를 나타냄
- 모든 Sejda 필드는 일반적으로 1개의 자식이 있는 `/Kids` 배열을 가짐

### 빠른 트랙 결정 트리
1. 작성 가능 여부 확인: `check_fillable_fields.py`
2. 작성 가능하지만 추출이 0을 반환하는 경우: pypdf 직접 추출 사용
3. 필드 구조 검사: `/T` (이름) 및 `/FT` (유형) 찾기
4. clone_reader_document_root 메서드를 사용하여 작성
5. 주석 대체 방법 불필요

이 접근 방식은 인식 시간을 약 5분에서 약 30초로 줄입니다.
