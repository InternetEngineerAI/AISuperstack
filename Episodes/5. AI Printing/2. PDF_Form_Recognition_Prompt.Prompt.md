## PDF Form Fields Recognition - Sejda and Similar Tools

### Quick Recognition Protocol

When working with PDF forms created by Sejda or similar online PDF editors, use this streamlined approach:

**Step 1: Quick Field Extraction**
If the standard `extract_form_field_info.py` script returns 0 fields but `check_fillable_fields.py` confirms fillable fields exist, use this direct extraction method:

```python
from pypdf import PdfReader

reader = PdfReader("path/to/form.pdf")
if "/AcroForm" in reader.trailer["/Root"]:
    fields = reader.trailer["/Root"]["/AcroForm"]["/Fields"]
    field_names = []
    for field in fields:
        field_obj = field.get_object()
        if "/T" in field_obj:
            field_names.append(field_obj["/T"])
    print("Field names:", field_names)
```

**Step 2: Fill Using pypdf Clone Method**
Sejda-created forms require using `clone_reader_document_root()` instead of `append_pages_from_reader()`:

```python
from pypdf import PdfReader, PdfWriter

reader = PdfReader("input.pdf")
writer = PdfWriter()

# Critical: Use clone_reader_document_root for Sejda forms
writer.clone_reader_document_root(reader)

# Define field values
field_values = {
    "FieldName1": "Value1",
    "FieldName2": "Value2",
    # ... etc
}

# Update fields
writer.update_page_form_field_values(writer.pages[0], field_values)

# Save
with open("output.pdf", "wb") as f:
    writer.write(f)
```

### Common Sejda Field Naming Patterns

Sejda typically uses these naming conventions:
- **Customer Info:** `Date`, `Estimate No`, `Name`, `Address`, `CustomerPhone`, `CustomerEmail`
- **Line Items:** `Description1-N`, `Qty1-N`, `Cost1-N`, `TotalCost1-N` (where N is the row number)
- **Totals:** `SubTotal`, `Taxes`, `GrandTotal`
- **Notes:** `Notes` (often multiline with flag 4096)

### Recognition Flags
- Sejda fields include `/Sejda` entry in field objects
- Field type `/FT: /Tx` indicates text field
- Flag `/Ff: 4096` indicates multiline text field
- All Sejda fields typically have `/Kids` array with 1 child

### Fast-Track Decision Tree
1. Check fillable: `check_fillable_fields.py`
2. If fillable but extract returns 0: Use pypdf direct extraction
3. Inspect field structure: Look for `/T` (name) and `/FT` (type)
4. Fill using clone_reader_document_root method
5. No need for annotation fallback method

This approach reduces recognition time from ~5 minutes to ~30 seconds.
