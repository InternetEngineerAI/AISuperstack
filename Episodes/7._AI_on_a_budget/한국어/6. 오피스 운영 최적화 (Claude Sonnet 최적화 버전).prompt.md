**컨텍스트:**
- 기술 스택: Microsoft Teams, Outlook, SharePoint, Jira, Excel
- 문제: 수동 주간/월간 대시보드를 통한 분절된 보고

**과제:**
하이브리드 근무의 5가지 병목 현상을 식별하고 도구 기반 해결책을 제안하십시오.  
각 병목 현상에 대해 다음을 제공하십시오:

1. 구체적인 예시를 포함한 근본 원인
2. 측정된 영향 (월별 손실 시간 정량화)
3. Teams/SharePoint/Jira/Power Automate를 활용한 해결책
4. 기대되는 성과 지표

**출력 형식 (Word 문서):**

섹션 1: 임원 요약
- 최대 3분 분량
- 병목 현상별 월간 손실 시간을 보여주는 재무 영향 표
- 예상 ROI를 포함한 전략적 권고 사항

섹션 2: 병목 현상 상세 분석  
예시 형식:
**병목 현상 #1: 비동기 커뮤니케이션 지연**
- 근본 원인: [구체적 이슈]
- 측정된 영향: [월별 시간/사건 수]
- 제안된 해결책: [구체적인 도구 구성]
- 사용 도구: [Teams/SharePoint 등]
- 기대 결과: [% 개선, 절감 시간]

섹션 3: 솔루션 프레임워크
- 비교 표: 병목 현상 | 해결책 | 사용 도구

섹션 4: 주간 보고 템플릿
다음 섹션 포함: KPI, 성과, 프로젝트 상태, 
위험/차단 요소, 자원 필요 사항, 다음 주 우선순위
(Excel/Jira 연동을 통한 반자동화 설계)

섹션 5: 90일 구현 로드맵
- 단계 1 (1–30일): 기반 구축
- 단계 2 (31–60일): 자동화
- 단계 3 (61–90일): 최적화
각 단계: 목표, 실행 항목, 성공 지표
