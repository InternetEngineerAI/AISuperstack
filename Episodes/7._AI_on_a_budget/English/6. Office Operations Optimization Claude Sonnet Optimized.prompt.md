Create a boardroom-ready operational efficiency audit for a 120-employee 
professional services firm (hybrid: 3 days office, 2 remote).

**Context:**
- Tech Stack: Microsoft Teams, Outlook, SharePoint, Jira, Excel
- Problem: Fragmented reporting via manual weekly/monthly dashboards
- Constraint: Use ONLY existing tools (limited IT resources, no new software)

**Task:**
Identify 5 hybrid-work bottlenecks and propose tool-based solutions. 
For each bottleneck provide:

1. Root cause with specific examples
2. Measured impact (quantify hours lost/month)
3. Solution using Teams/SharePoint/Jira/Power Automate
4. Expected outcome metrics

**Output Format (Word document):**

Section 1: Executive Summary
- 3-minute read maximum
- Financial impact table showing monthly hours lost per bottleneck
- Strategic recommendations with expected ROI

Section 2: Detailed Bottleneck Analysis
Example format:
**Bottleneck #1: Asynchronous Communication Lag**
- Root Cause: [specific issues]
- Measured Impact: [hours/incidents per month]
- Proposed Solution: [specific tool configuration]
- Tools Used: [Teams/SharePoint/etc]
- Expected Outcome: [% improvement, hours saved]

Section 3: Solution Framework
- Comparative table: Bottleneck | Solution | Tools Used

Section 4: Weekly Reporting Template
Include sections for: KPIs, Accomplishments, Project Status, 
Risks/Blockers, Resource Needs, Next Week Priorities
(Design for semi-automation via Excel/Jira integrations)

Section 5: 90-Day Implementation Roadmap
- Phase 1 (Days 1-30): Foundation
- Phase 2 (Days 31-60): Automation
- Phase 3 (Days 61-90): Optimization
Each phase: objectives, action items, success metrics

**Style:** Professional, analytical, action-oriented. Use bullet points 
sparingly—favor prose in bottleneck analysis. Include tables for data 
comparison and reporting templates.
