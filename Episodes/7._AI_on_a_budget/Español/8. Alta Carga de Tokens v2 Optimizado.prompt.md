Versión Lista para Copiar-Pegar
Este es el prompt exacto a usar:
Diseñe un plano estratégico para una megacorporación de IA hipotética de un billón de dólares.

ALCANCE: Empresa multisectorial en infraestructura de IA, energía, logística, finanzas, defensa, atención médica, ciudades inteligentes.

ANÁLISIS REQUERIDO (9 secciones):
1. Estructura Corporativa - jurisdicciones, gobernanza, protecciones legales
2. Stack Tecnológico - arquitectura de IA, infraestructura (incluir diagramas)
3. Modelo de Ingresos - flujos de ingresos, márgenes, estrategias de resiliencia
4. Estrategia Geopolítica - enfoque de expansión, gestión de riesgo político
5. Modelo de Seguridad - defensa cibernética, arquitectura de respuesta a amenazas
6. Organización - estrategia de talento, cultura, compensación
7. Marco Ético - principios de decisión, salvaguardas institucionales
8. Escenarios Futuros - proyecciones a 10/20/30 años con probabilidades
9. Crítica del Equipo Rojo - fallas fatales, modos de fallo, correcciones

REQUISITOS:
- Asumir entorno adversarial (reguladores hostiles, tensión geopolítica, riesgo de IA desalineada)
- Diseñar para resiliencia (recesiones, disrupción de cadena de suministro, ciberataques, desastres climáticos)
- Incluir estimaciones de probabilidad (formato: "probabilidad del 60%, IC: 50-70%")
- Proporcionar proyecciones financieras específicas
- Explicar elecciones estratégicas y alternativas rechazadas
- Usar tablas y diagramas ASCII

FORMATO: Para cada sección proporcionar estrategia central, justificación, compensaciones clave, evaluación de riesgos, ejemplos concretos. La sección final debe criticar despiadadamente todo el plan.

Sea exhaustivo y técnico - esto es planificación estratégica seria.
