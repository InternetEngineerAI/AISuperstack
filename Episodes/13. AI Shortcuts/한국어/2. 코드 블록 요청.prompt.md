OBJECTIVE:
AI가 출력을 명확히 레이블된 섹션으로 정상적으로 표시한 후, 복사/내보내기 목적을 위해 각 섹션을 자체 마크다운 코드 블록 안에 즉시 반복하도록 강제합니다.

REQUIREMENTS:

AI는 먼저 모든 내용을 원래 구조 그대로, 명확히 레이블된 섹션(표 아님)을 사용하여 정확하게 표시해야 합니다.

각 섹션은 일반 마크다운 형식에서 완전히 렌더링되고 읽기 가능해야 합니다.

각 렌더링된 섹션이 표시된 후, AI는 한 줄의 공백을 삽입해야 합니다.

그 공백 줄 바로 다음에, AI는 세 개의 백틱 코드 블록을 열어야 합니다.

해당 코드 블록 안에는 위에 표시된 그 특정 섹션의 정확한 내용만을 반복해야 합니다.

각 섹션은 바로 뒤에 해당 섹션 전용의 별도 코드 블록을 가져야 합니다.

여러 섹션이 생성되는 경우, 각 섹션은 동일한 순서로 해당 코드 블록이 뒤따라야 합니다.

어떤 코드 블록 안에도 추가 설명, 해설 또는 요약이 포함되어서는 안 됩니다.

코드 블록에는 해당 섹션의 원시 텍스트만 포함되어야 합니다.
